# BWOP

[<img alt="Made with love at the Recurse Center" src="https://cloud.githubusercontent.com/assets/2883345/11325206/336ea5f4-9150-11e5-9e90-d86ad31993d8.png" height="20">](https://www.recurse.com/)

This is BWOP, a small balance game developed in react. The "B" stands for balance. The goal of the game is to stay upright as long as possible.

## Controls

Each arm is controlled at the joins by two keys: `Z` and `,` control the left and right shoulder joints, and `X` and `.` control the left and right elbow joints. `R` resets the game.

## Setup

To install dependencies:

```bash
bun install
```

To start a development server:

```bash
bun dev
```

To build it:

```bash
bun run build
```
